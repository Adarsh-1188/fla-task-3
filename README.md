# FLA Task 3 – PDA and CFG Case Studies

Course: 21CSC301T – Formal Language and Automata
Assessment: CLA-2 – Assessment Task 3
SDG: SDG 9 – Industry, Innovation and Infrastructure

## Case studies
1. Arithmetic Expression Validation
2. Balanced Parentheses Validation
3. Palindrome Checking

This project demonstrates CFG/PDA models, derivations, stack behavior, accepted/rejected strings, ambiguity/determinism discussion, and why finite automata are insufficient for the selected context-free patterns.

## Run
```bash
python app.py
python -m pda_cfg.cli
python -m unittest discover -s tests -v
```
